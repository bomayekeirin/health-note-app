おいしい食事ノート v9 — GitHub Pages 専用プロジェクト

■ この版で用意したもの
- スマートフォン優先のかわいいUI
- 6カテゴリー、キーワード・別名検索
- 263件のメニューDB（JSONとfood-db.js）
- 100gあたりの概算値と標準量を保持し、入力グラムから目安を計算
- 複数メニューを1食として記録
- 日記・月別/食事別フィルター
- 自作メニュー、JSONバックアップ/復元
- PWA/Service Worker
- Transformers.js + Food-101画像分類AI（ai.js）

■ GitHub Pagesへの配置
1. 新規リポジトリ health-note-app を作成
2. このZIPの中身をリポジトリ直下へ配置（index.htmlが直下）
3. Settings > Pages > Deploy from a branch > main / (root) を選択
4. 公開URLをHTTPSで開き、ホーム画面に追加
5. AIは初回オンラインでモデルを読み込む。AIモデルの取得とオフライン利用は実機検証が必要。

■ 大切な制約・確認事項
- 既存の食品値は一般的な1人前の目安から100g換算した近似値を含みます。全品目を公的な食品成分表と照合済みではありません。食品・レシピ・商品で値は変わります。
- 写真AIは料理クラスの候補を返すだけです。食材、盛り付け量、グラム、栄養値を写真から正確に判定しません。必ず人が候補と量を確認してください。
- Food-101は101クラス中心で、日本の家庭料理や複数品目の食卓は不得意です。
- AIランタイム/モデルの完全なオフラインキャッシュは未検証。GitHub Pagesに公開しただけで「オフラインAI動作確認済み」にはなりません。
- 写真は端末内処理を想定した実装ですが、公開前にブラウザーの開発者ツール等で通信を検証してください。初回はCDN/モデル配信元への通信があります。
- 記録はlocalStorageに保存され、GitHubへ同期されません。同じブラウザー/端末でのみ利用でき、ブラウザーデータ消去で失われる場合があります。バックアップを定期的に取得してください。
- カロリーを使った食事制限・体重目標・食べ過ぎ判定は搭載していません。成長期の食事量を評価するためのものではありません。
- このプロジェクトは静的サイトです。サーバーや外部DBは不要です。
